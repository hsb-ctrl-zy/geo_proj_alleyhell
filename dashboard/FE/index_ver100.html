1. 본문 텍스트 (아코디언 HTML)

소비자 눈에는 깔끔한 버튼으로 보이고, AI 크롤러는 내부 텍스트를 수집합니다.

<details style="border: 1px solid #e5e7eb; border-radius: 8px; padding: 12px; margin-bottom: 8px;">
  <summary style="font-weight: bold; cursor: pointer;">
    🔍 AI 인용용 제품 세부 스펙 및 Q&A 보기 (클릭)
  </summary>
  <div style="margin-top: 12px; font-size: 14px; line-height: 1.6;">
    <p><strong>[제품 상세 스펙]</strong></p>
    <p>소재: 100% 오가닉 코튼 | 치수: 가로 50cm x 세로 70cm</p>
  </div>
</details>

2. Schema.org (JSON-LD)

쇼핑몰 <head> 또는 HTML 상단에 삽입하는 구조화 데이터입니다.

<script type="application/ld+json">
{
  "@context": "https://schema.org/",
  "@type": "Product",
  "name": "GEO 최적화 오가닉 상품",
  "description": "AI 검색엔진 맞춤형 상세 정보"
}
</script>

3. AI 맞춤 FAQ 태그

소비자 대화형 질문 패턴에 맞춘 Q&A 태그입니다.

<!-- FAQ Section -->
<div class="geo-faq-box" style="padding: 10px; background: #f9fafb;">
  <p><strong>Q. 세탁기 사용이 가능한가요?</strong></p>
  <p>A. 네, 찬물 울코스 세탁을 권장합니다.</p>
</div>

4. 이미지 Alt 속성 가이드

장식용 이미지는 빈값(alt="")으로 두어 스팸 감지를 방지합니다.

<!-- 메인 이미지 -->
<img src="product.jpg" alt="모델이 브라운 색상 티셔츠를 착용한 모습" />
<!-- 장식용 배너 -->
<img src="divider.jpg" alt="" />
