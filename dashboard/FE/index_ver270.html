Starter 이상 요금제 전용 기능

상품페이지의 약점, 주의사항, 강점에 대한 상세 AI 분석 리포트는 Starter 요금제 이상부터 제공됩니다.

상품페이지 약점 진단

1. 상품명 키워드 스터핑 (스팸 분류 위험 높음)

⚠️ 진단 결과

동일하거나 유사한 키워드가 반복 사용되어 AI 크롤러 및 검색 엔진 스팸 알고리즘에 걸릴 위험이 높습니다.

💡 개선 방향: 핵심 키워드 1~2개 위주로 자연스러운 문장형 명칭을 구성하세요.
2. 이미지 Alt 속성 부재 (AI 크롤러 파싱 불가)

⚠️ 진단 결과

상세페이지내 주요 상품 이미지에 Alt(대체 텍스트) 태그가 지정되어 있지 않아 AI 봇이 상품 컨텐츠를 읽지 못합니다.

💡 개선 방향: 이미지마다 alt="상품 특징 설명" 속성을 추가하여 검색 노출도를 높이세요.

상품페이지 주의 및 개선점 진단

1. JSON-LD 내 필수 신뢰 요소(hasMerchantReturnPolicy) 속성 누락

⚡ 진단 결과 및 위협요인

구조화 데이터(JSON-LD)에 hasMerchantReturnPolicy(반품/환불 정책) 속성이 누락되어 있습니다. 이는 최신 검색엔진 및 AI 추천 모델이 상품 판매자의 신뢰도를 측정할 때 부정적인 영향을 주며, 추천 상품 등록 시 배점 감점 요소가 됩니다.

💡 개선 방향: JSON-LD Product 메타데이터 내에 반품 일수, 환불 방법 등 명확한 hasMerchantReturnPolicy 스키마 구조를 보완하여 쇼핑몰 신뢰 지수를 향상시키세요.
2. 메타 태그 내 배송 정보(shippingDetails) 정의 미비

⚡ 진단 결과 및 위협요인

배송 지역 및 배송비 관련 구조화 데이터가 구체적으로 기재되어 있지 않아 AI 쇼핑 검색봇이 상품의 정확한 최종 구매가를 산정하는 데 어려움을 겪고 있습니다.

💡 개선 방향: OfferShippingDetails 속성을 구강하여 기본 배송비와 무료 배송 기준 단가를 명시해 주세요.

상품페이지 강점 진단

1. 본문 텍스트 분량 및 정보 구조 양호

✅ 진단 결과

상품에 대한 설명 텍스트 분량이 충분하여 AI 검색엔진이 상품의 핵심 정보와 특징을 파악하기에 매우 적합한 기반을 갖추고 있습니다.

👏 유지 및 활용: 이 텍스트 데이터를 바탕으로 구조화 데이터(JSON-LD) 및 FAQ 형태를 접목하면 AI 검색 노출도가 더욱 극대화됩니다.

2. Schema.org

쇼핑몰 <head> 또는 HTML 상단에 삽입하는 구조화 데이터입니다.

구조화 데이터 코드 
<script type="application/ld+json">
{
  "@context": "https://schema.org/",
  "@type": "Product",
  "name": "GEO 최적화 오가닉 코튼 침구 세트",
  "description": "100% 국제 인증 오가닉 코튼으로 제작되어 민감성 피부도 안심하고 사용할 수 있는 친환경 침구 세트입니다. 뛰어난 통기성과 부드러운 감촉을 자랑하며, 찬물 울코스 세탁이 가능하여 위생적으로 관리할 수 있습니다.",
  "hasMerchantReturnPolicy": {
    "@type": "MerchantReturnPolicy",
    "applicableCountry": "KR",
    "returnPolicyCategory": "https://schema.org/MerchantReturnFiniteReturnWindow",
    "merchantReturnDays": 7,
    "returnMethod": "https://schema.org/ReturnByMail"
  },
  "offers": {
    "@type": "Offer",
    "shippingDetails": {
      "@type": "OfferShippingDetails",
      "shippingRate": {
        "@type": "MonetaryAmount",
        "value": "3000",
        "currency": "KRW"
      }
    }
  }
}
</script>
