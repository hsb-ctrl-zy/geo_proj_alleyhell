### GEO (Generative Engine Optimization) 진단 및 교정 솔루션 파이프라인

> 생성형 AI 검색 환경에서 이커머스 콘텐츠의 인용 가능성을 정량 평가하고 최적화하는 데이터 파이프라인 및 진단 모델 구축 프로젝트입니다.

> multi-team1-project repository copy

#### 🛠 Tech Stack
- **Language & Analysis:** Python, Pandas, NumPy, Scikit-learn
- **Database:** MySQL (DB 적재 및 데이터 파이프라인 구축)

#### 📌 Key Architecture & Role (Technical PM)
- **데이터 파이프라인 및 DB 설계 (`DB적재`):** 53만 건 규모의 데이터 적재 구조 설계 및 입출력(I/O) 인터페이스 총괄
- **비정형 데이터 추출 및 분석 (`ocr`, `JSON-LD_분석`):** 웹 구조화 데이터 및 이미지 텍스트 추출·정제 로직 구현
- **진단 및 교정 모델링 (`진단 모델`, `교정코드`, `평가 코드`):** 정량적 평가 지표 기반 진단 알고리즘 구현 및 성능 검증
